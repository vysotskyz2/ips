# Кадастровая карта Республики Беларусь (FastAPI + PostGIS + MapLibre GL)

Веб-приложение интерактивной кадастровой карты Республики Беларусь с отображением земельных участков, капитальных строений (2D/3D) и просмотром полного перечня организаций внутри каждого здания при клике на карту.

Все используемые инструменты и источники данных в проекте **100% бесплатные и открытые (Open-Source)**.

---

## Возможности

* **Интерактивная векторная карта всей Беларуси (MapLibre GL JS + OpenFreeMap + MVT):**
  * Плавное отображение полигонов зданий и земельных участков в 2D и 3D (экструзия по этажности).
  * Генерация бинарных векторных тайлов **MVT (`.pbf`)** на бэкенде (`/api/v1/tiles/cadastral/{z}/{x}/{y}.pbf`) через PostGIS `ST_AsMVT` или встроенный Python MVT 2.1 энкодер.
* **Клик по любому зданию на карте РБ -> Содержимое здания:**
  * При нажатии на здание открывается боковая карточка с двумя вкладками:
    1. **«Организации внутри (N)»** — все компании, магазины, банки, аптеки, кафе, ИТ-офисы и госучреждения внутри здания с фильтрацией по категориям, поиском, указанием этажа, помещения, УНП, времени работы, телефона и сайта.
    2. **«Кадастровый паспорт»** — кадастровый и инвентарный номер ЕГРНИ, адрес, этажность, год постройки, площадь застройки ($м^2$), а также сведения о земельном участке (кадастровый квартал, назначение, вид права, кадастровая стоимость в BYN).
  * При клике на любое здание Беларуси, ещё не сохранённое в локальной БД, сервер автоматически подгружает контур и организации внутри него из **OpenStreetMap Overpass API**.
* **Универсальный поиск:**
  * Мгновенный поиск по кадастровому номеру, адресу, названию здания, названию организации или УНП с автоматическим перелётом камеры (`flyTo`) к объекту.

## Быстрый запуск через `uv` (локально без Docker)

В проекте используется пакетный менеджер **[uv](https://docs.astral.sh/uv/)**. Приложение поддерживает автоматический запуск с локальной базой данных и предзагруженным реестром ключевых зданий и организаций всех областных центров РБ (Минск, Брест, Гродно, Гомель, Витебск, Могилёв):

```powershell
# 1. Синхронизация окружения и зависимостей по uv.lock
uv sync

# 2. Запуск сервера FastAPI
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

После запуска откройте в браузере:
* Карта РБ: **http://127.0.0.1:8000**
* Документация Swagger API: **http://127.0.0.1:8000/docs**

## Запуск промышленного стека с PostgreSQL + PostGIS (Docker Compose)

```powershell
docker compose up --build -d
```

Сервер будет доступен на `http://localhost:8000`, а БД PostGIS — на порту `5432`.

## Импорт геоданных Беларуси из OpenStreetMap

1. **Онлайн-импорт зданий и организаций выбранного города РБ через Overpass API:**
   ```powershell
   uv run python scripts/import_osm_to_postgis.py --city Минск --limit 200
   ```
2. **Скачивание полного дампа всей Беларуси с Geofabrik (`belarus-latest.osm.pbf`):**
   ```powershell
   uv run python scripts/download_belarus_osm.py
   ```
